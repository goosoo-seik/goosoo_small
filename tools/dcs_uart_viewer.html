    열 설명

    _ref 기준→PID→_out 지령→AD5663 DAC · TB2→외부 점호기→SCR→부하→전압·전류 센서→AD7705 ADC adc_amp · adc_volt→_in 측정↺ PID로
    t_ms
    부팅 후 경과 시간. 메인 루프 1회를 2ms로 세므로 줄 간격이 500에서 벗어나면 루프가 느려진 것입니다.
    step
    제어 상태머신 sConStep. 0~6 초기화(운전 아님), 10·11 ADC 대기, 100번대 CC, 200번대 CV. 0.5초마다 찍는 순간값이라 대부분 10·11로 보입니다.
    mode
    0 = CC 정전류, 1 = CV 정전압.
    stable
    PID 수렴. 오차 0.5%(CV 1.0%) 이내가 100회 이어지면 1, 설정값이 바뀌면 0.
    adc_amp · adc_volt
    AD7705 원시값(0~65535). 보정 전 값이며 최대값은 정격의 125%에 해당합니다. 65535 근처면 입력 포화.
    amp_ref · volt_ref
    PID 기준값. 운전자 설정(fOperAmp/fOperVolt)을 그대로 복사합니다. CC에서 volt_ref는 전압 상한, CV에서 amp_ref는 전류 상한입니다.
    amp_in · volt_in
    출력단을 실제로 측정한 값. 오프셋·게인 보정 후이며 stable=1이면 이동평균입니다.
    amp_out · volt_out
    PID가 점호기에 주는 지령을 A·V로 환산한 값. CC에서는 volt_out, CV에서는 amp_out이 갱신되지 않습니다(그쪽 DAC는 최대로 고정).
    adc_err
    0 정상, 1 AD7705 응답 없음, 2 ADC 상태머신 이상.
    alarm · drop
    alarm은 활성 알람 개수 합(비트마스크 아님). drop은 송신 버퍼가 차서 버린 디버그 줄 수.
